01 尺寸公差与配合 GB/T 1800.1-2020 · GB/T 1800.2-2020

1.1 基本术语

尺寸公差（linear size tolerance）描述「尺寸」允许的变动范围，是零件互换性的基础。核心概念：

术语定义 / 说明符号
基本尺寸设计给定的尺寸，如 φ50D / d
极限尺寸允许尺寸变化的两个界限：最大极限尺寸、最小极限尺寸Dmax/dmax、Dmin/dmin
实际尺寸通过测量获得的尺寸（须在极限尺寸范围内）Da/da

下偏差最小极限尺寸 − 基本尺寸EI（孔）· ei（轴）
基本偏差确定公差带相对零线位置的偏差，即靠近零线的那个偏差（JS/js 例外）—
尺寸公差允许尺寸的变动量，恒为正值、无正负号T = |ES − EI|
公差带 = 公差带大小（标准公差值）× 公差带位置（基本偏差）。
尺寸标注示例：φ50+0.025
0 表示基本尺寸 φ50、上偏差 +0.025、下偏差 0。

要点补充：术语关系链与合格判定

基本尺寸 → 极限尺寸（上/下界限）→ 偏差（ES/es、EI/ei）→ 公差 T = |ES − EI|
合格判定：Dmin ≤ 实际尺寸 Da ≤ Dmax（含等于极限尺寸）
  • 公差是设计时给定的允许变动量；误差是加工产生的实际偏离。误差 ≤ 公差 → 合格。
  • 公差带图：零线代表基本尺寸；纵坐标为偏差（单位常取 μm）；公差带高度 = 公差值，位置由基本偏差确定。
  • 尺寸偏差必须带正负号书写（+0.025、−0.009、0），公差不带符号（0.025）。
  • φ 前缀表示直径尺寸（圆柱面/孔轴），R 表示半径，标注时基本尺寸必须完整。

1.2 标准公差等级 IT01 ~ IT18

标准公差（standard tolerance）是国标规定的公差值，用公差等级（IT）表示。共 20 级：IT01、IT0、IT1 ~ IT18。等级数字越大，公差值越大、精度越低、越容易加工。

等级精度 / 典型用途
IT01 · IT0 · IT1超精密级：量块、计量器具、超精密机械
IT1 ~ IT4精密级：精密量规、高精度仪器零件
IT5 ~ IT7常用配合级：机床主轴、齿轮、轴承配合（如 H7/g6、H7/p6）
IT8 ~ IT11一般精度：普通机械零件、一般配合（如 H9/d9）
IT12 ~ IT14较粗：冲压件、铸件、锻件加工面
IT15 ~ IT18粗加工、非配合尺寸

同一公差等级下，基本尺寸越大，公差值越大；同一基本尺寸下，等级数字越大，公差值越大。常用示例（φ30、φ50 段经典值）：

基本尺寸IT6IT7IT8
φ3013 μm21 μm33 μm
φ5016 μm25 μm39 μm

要点补充：公差等级与典型加工方法

公差等级典型加工方法（参考）
IT5研磨、珩磨、精磨
IT6 ~ IT7精车、精镗、磨削（配合面常用）
IT8 ~ IT9半精车、铣、钻扩（一般配合面）
IT10 ~ IT11粗车、粗铣、钻孔
IT12 ~ IT14冲压、铸造、锻造后的非配合面
IT15 ~ IT18自由尺寸、粗加工余量面
等级选择原则：在满足功能（配合性质、对中、运动精度）前提下尽量选较粗等级，以降低成本。IT6~IT7 是机械配合面最常用区间。

1.3 基本偏差（公差带位置）

基本偏差是靠近零线的那个偏差（JS/js 为对称偏差 ±IT/2），用字母代号表示。孔的基本偏差代号 A ~ ZC 共 28 种（大写），轴为 a ~ zc 共 28 种（小写）。

对象代号范围规则
孔A ~ H下偏差 EI 为正（H 的 EI = 0，基孔制基准孔）
孔JS对称偏差，es/es = ±IT/2
孔J ~ ZC上偏差 ES 为负（J、K、M、N 部分特殊）
轴a ~ h上偏差 es 为负（h 的 es = 0，基轴制基准轴）
轴js对称偏差，±IT/2
轴j ~ zc下偏差 ei 为正

φ50 尺寸段部分基本偏差示例值（μm，配合查表计算用）：

轴代号es / ei孔代号ES / EI

f6−25 / −41G7+34 / +9
k6+2 / +18K7+7 / −18
n6+17 / +33N7+10 / −15
p6+26 / +42P7−8 / −33
s6+43 / +59S7+8 / −17

要点补充：基本偏差系列分布规律

  • 轴的 a ~ h：公差带在零线下方（es 为负），越靠近 h 越接近零线，适合间隙配合；h 是分界（es = 0）。
  • 轴的 j ~ zc：公差带在零线上方（ei 为正），越靠后过盈越大，适合过盈配合；js 对称跨零线。
  • 孔与轴完全镜像：A ~ H 下偏差 EI 为正（H 为 0）；J ~ ZC 上偏差 ES 为负。
  • 同名配合换算：H7/g6 ↔ G7/h6、H7/p6 ↔ P7/h6，基本偏差代号与基准代号互换、公差等级跟随各自要素。
易错点：基本偏差是「靠近零线的那个偏差」而非固定上/下偏差——a~h 与 A~H 是 es/ES 靠近零线，j~zc 与 J~ZC 是 ei/EI 靠近零线；只有 JS/js 例外（对称）。

1.4 配合：间隙 / 过渡 / 过盈

配合是基本尺寸相同的孔与轴的结合关系，由两公差带的相对位置决定：

  • 间隙配合：孔公差带完全在轴公差带之上（孔最小 ≥ 轴最大），产生间隙 X，用于相对运动或轻松装配。
  • 过盈配合：孔公差带完全在轴公差带之下（孔最大 ≤ 轴最小），产生过盈 Y，用于传递扭矩、固定连接。
  • 过渡配合：两公差带相互交叠，可能产生间隙也可能产生过盈，用于定位对中（如轴承座、齿轮定位）。
Xmin = EI − es > 0
可间隙 X，可过盈 Y
Ymax = EI − es < 0

基孔制与基轴制

  • 基孔制：基准孔的基本偏差代号 H（EI = 0），与各种基本偏差的轴组成配合。代号如 φ50H7/g6。
  • 基轴制：基准轴的基本偏差代号 h（es = 0），与各种基本偏差的孔组成配合。代号如 φ50F8/h7。

配合代号标注规则：基本尺寸 + 孔公差带代号 / 轴公差带代号，分子为孔、分母为轴。工程上优先采用基孔制（减少刀具、量具规格），基轴制用于轴为标准件（如滚动轴承外圈、冷拉圆钢）的场合。

口诀：H 是孔基准（下偏差 0），h 是轴基准（上偏差 0）；g/f/d 偏下成间隙，p/r/s/t 偏上成过盈，k/n/js 居中为过渡。

要点补充：常用配合的典型应用

配合代号（基孔制）类型典型应用
H7/g6小间隙滑动轴承、精密导向、分度机构（可润滑运动）
H7/f6小间隙一般滑动配合、齿轮与轴（带键）
H8/f7 · H8/d9间隙较松的转动配合、大间隙轴承
H7/h6最小间隙为零定位配合、可轻敲拆装（如联轴器定位）
H7/js6 · H7/k6过渡精密定位、需要稍紧的定位（齿轮毂、轴承座）
H7/n6过渡偏过盈较大冲击下的定位、不可轻易拆卸
H7/p6 · H7/r6过盈压入固定（传递扭矩，需键辅助或小扭矩）
H7/s6较大过盈热装/冷装固定，传递大扭矩
  • 选择配合时考虑：载荷大小与性质、对中精度、是否常拆卸、材料与温差、润滑条件。
  • 基准制优先顺序：基孔制（一般）→ 基轴制（标准件轴、冷拉料、一轴多配）→ 非基准制（特殊情况）。

1.5 间隙、过盈与配合公差计算

间隙配合：Xmax = ES − ei，Xmin = EI − es（X ≥ 0）
过盈配合：Ymax = EI − es，Ymin = ES − ei（Y ≤ 0，代数值）
配合公差：Tf = |Xmax − Xmin| = |Ymin − Ymax| = T孔 + T轴

示例：计算 φ50H7/g6 的极限间隙与配合公差。

孔 φ50H7：ES = +0.025，EI = 0；轴 φ50g6：es = −0.009，ei = −0.025
Xmin = EI − es = 0 − (−0.009) = +0.009 mm
Xmax = ES − ei = 0.025 − (−0.025) = +0.050 mm
Tf = Xmax − Xmin = 0.050 − 0.009 = 0.041 mm（校验：T孔0.025 + T轴0.016 = 0.041）
易错点：偏差带正负号参与运算；间隙/过盈均为「孔 − 轴」的代数差；配合公差恒为正，且等于孔、轴公差之和。

要点补充：过渡配合的极限计算

过渡配合的公差带相互交叠，需同时计算最大间隙与最大过盈：

例：φ30H7（+0.021/0）与 φ30n6（+0.028/+0.015）
最大过盈 Ymax = EI − es = 0 − 0.028 = −0.028 mm（过盈 0.028）
最大间隙 Xmax = ES − ei = 0.021 − 0.015 = +0.006 mm（间隙 0.006）
Tf = |Ymax − Xmax| = 0.028 + 0.006 = 0.034 = T孔(0.021) + T轴(0.013) ✓

判断配合类型的两步法：① 看孔带是否整体在轴带上方（间隙）或下方（过盈）；② 交叠则为过渡，再用 EI − es 与 ES − ei 求出极限值。

查表路径：基本尺寸段（如 >40~50 mm）→ 公差等级（IT 值）→ 基本偏差代号（es/ei 或 ES/EI）→ 组合即得极限偏差。具体数值以 GB/T 1800.2-2020 极限偏差表为准。
02 几何公差（形位公差） GB/T 1182-2018

2.1 几何特征符号（15 项）

GB/T 1182-2018 把几何公差分为形状、方向、位置、跳动四大类（另计轮廓两类）。判断归属的要点：形状公差无基准，方向/位置/跳动公差需基准；线、面轮廓度无基准时为形状公差，有基准时为位置公差。

类别符号特征项目类别符号特征项目
形状 直线度 方向 平行度
平面度 垂直度
圆度 倾斜度
圆柱度 位置 位置度
轮廓 线轮廓度 同心度 / 同轴度
面轮廓度 对称度
跳动 圆跳动 全跳动
记忆法：形状四项「直平圆柱」无基准；方向三项「平垂斜」、位置四项「位同对（位置/同心同轴/对称）」、跳动两项均有基准；轮廓「线面」视有无基准分属形状或位置。

要点补充：特征项目与被测要素

  • 直线度、圆度、圆柱度、平行度、垂直度、倾斜度、同轴度、圆跳动等既可用于中心要素（轴线、中心面）也可用于轮廓要素（表面），标注时指引线指向不同。
  • 同轴度与同心度共用符号 ◎：同心度用于点要素（如圆心），同轴度用于轴线要素——概念上是同一符号的两类应用。
  • 2018 版标准将同心度与同轴度分别列出（合计 15 项特征名称）；传统教材常按 14 项合并表述，二者均正确，注意题目口径。
  • 几何公差值前加 φ（如 φ0.05）表示公差带为圆柱形（轴线直线度、位置度常用）；加 Sφ 表示圆球形公差带。

2.2 公差框格与基准标注

几何公差采用公差框格标注：第一格写特征符号，第二格写公差值（可为 φ 前缀表示圆形公差带，可带修饰符），第三格及以后写基准字母。用带箭头的指引线把框格引到被测要素；基准用基准三角形 + 字母标注。

图 2-1 公差框格标注示例：顶面对底面 A 的平行度公差 0.02 mm
  • 被测要素：图样上给出几何公差要求的要素（表面、轴线、中心面）。
  • 基准要素：用于确定被测要素方向或位置的要素（图 2-1 中的底面 A）。
  • 公差值前加 φ（如 φ0.05）表示公差带为圆柱形（常用于轴线直线度、位置度）；加 Sφ 表示圆球形公差带。
  • 附加符号：Ⓜ 最大实体要求、Ⓛ 最小实体要求、Ⓡ 可逆要求、CZ 公共公差带等。

要点补充：基准体系与理论正确尺寸

  • 基准体系（三基面体系）：按 A|B|C 顺序建立——第一基准 A 限制最多自由度，第二基准 B 次之，第三基准 C 最后，形成空间直角坐标系（对应零件的定位基准、导向基准、定程基准）。
  • 理论正确尺寸（TED）：用方框框起的尺寸（如 50），不带公差，仅确定要素的理想位置/方向；实际位置由位置度等公差控制。
  • 基准标注：基准三角形可落在轮廓线、尺寸界线或轴线（中心要素）上；同一基准可被多个框格引用。
  • 被测要素标注：指引线箭头指向轮廓线或其延长线（表面），指向尺寸线（轴线/中心平面）时用尺寸线对齐方式。

易错点：形状公差只控制形状误差，不控制方向与位置；方向公差控制方向 + 形状，但不控制位置；位置公差同时控制位置、方向与形状误差（GB/T 1182-2018 明确规定）。

要点补充：圆跳动与全跳动的区别

  • 圆跳动：被测要素绕基准轴线回转一周（单点截面测量）时指示表读数的最大变动量，属于单一截面上的控制。
  • 全跳动：被测要素连续回转且指示表沿轴向移动时读数的最大变动量，控制整个表面的跳动。
  • 全跳动可同时控制圆度、同轴度、直线度与垂直度的综合效果，是跳动类中最严的要求。
  • 径向圆跳动 ≠ 同轴度：跳动包含表面形状误差的影响，同轴度仅针对轴线位置。
公差带本质：公差值 t 定义的区域，被测实际要素（提取要素）必须完全落在该区域内才算合格。公差带形状由特征项目与被测要素类型共同决定。
03 公差原则（尺寸与几何公差的关系） GB/T 4249-2018 · GB/T 16671-2018

3.1 独立原则（缺省原则）

按 GB/T 4249-2018，图样上未作特殊标注时，每个要素的尺寸公差与几何公差相互独立、分别满足——尺寸合格不保证形状、方向、位置合格，反之亦然。这是默认原则，绝大多数图样都在此规则下工作。

要点补充：独立原则下的验收逻辑

  • 尺寸按尺寸公差验收（两点法测局部实际尺寸），几何误差按几何公差验收（专用量仪），两项分别判定，互不补偿。
  • 示例：φ40h6 轴（尺寸公差 16μm）标注直线度 0.01——即使轴直径全部合格，轴线弯曲超过 0.01 仍判不合格；反之亦然。
  • 独立原则与 ISO 8015 的独立原则一致；只有当图样明确标注 ⓔ/Ⓜ/Ⓛ/Ⓡ 时才进入相关要求。

3.2 相关要求（尺寸与几何相互关联）

当功能需要尺寸公差与几何公差协调工作时，可采用相关要求，标注于公差值后（几何公差侧）或尺寸公差后：

要求符号作用对象核心规则典型用途
包容要求（Envelope Requirement） ⓔ 单一尺寸要素（孔/轴），标在尺寸公差带代号后 实际要素不得超越最大实体边界；局部实际尺寸不得超出最小实体尺寸 保证配合性质稳定、可装配性
最大实体要求（MMR） Ⓜ 尺寸要素的几何公差，标在公差值后 几何公差可随尺寸偏离最大实体尺寸而获得补偿（公差带扩大） 保证可装配性，如螺栓过孔位置度
最小实体要求（LMR） Ⓛ 尺寸要素的几何公差，标在公差值后 几何公差可随尺寸偏离最小实体尺寸而获得补偿 保证最小壁厚 / 强度
可逆要求（RPR） Ⓡ 与 MMR / LMR 连用，标在其后 尺寸公差与几何公差互相补偿（双向） 优化工艺性，充分利用公差
最大实体尺寸 MMS：孔 = 最小极限尺寸；轴 = 最大极限尺寸（材料最多状态 MMC）
最小实体尺寸 LMS：孔 = 最大极限尺寸；轴 = 最小极限尺寸（材料最少状态 LMC）

MMR 补偿示例：φ20 孔位置度标注 ⊕ φ0.1 Ⓜ A B C。孔在最大实体状态（φ20 最小孔径）时位置度公差为 φ0.1；当实际孔径为 φ20.2（偏离 MMC 0.2）时，位置度公差可扩大为 φ0.1 + 0.2 = φ0.3。

一句话区分：包容要求「ⓔ」只管尺寸与形状/方向协调（约束边界）；MMR「Ⓜ」让几何公差随尺寸放松而变大；RPR「Ⓡ」把尺寸公差与几何公差「打通」，双向补偿。
易错点：最大实体要求与最小实体要求仅适用于尺寸要素；一旦采用 MMR/LMR/RPR，GB/T 4249 的独立原则不再适用（GB/T 16671-2018 明确规定）。

要点补充：边界概念与补偿计算

  • 最大实体边界（MMB）：由最大实体尺寸与对应几何公差共同确定的一个理想边界。包容要求 ⓔ 下，被测要素的实际轮廓不得超越 MMB，同时局部实际尺寸不得超出最小实体尺寸。
  • MMR 补偿公式：允许的几何公差 = 标注公差 + |实际尺寸 − 最大实体尺寸|（孔取孔径增大方向，轴取直径减小方向）。
  • 例：φ20 孔标注 ⊕ φ0.1 Ⓜ A B C，孔径为 φ20.2 时允许位置度 = 0.1 + 0.2 = φ0.3。
  • 可逆要求 Ⓡ：在 MMR/LMR 基础上双向补偿——几何误差小时尺寸公差也可放宽，最大限度利用公差。
  • 符号位置规则：ⓔ 标在尺寸公差带代号之后（如 φ50H7ⓔ）；Ⓜ/Ⓛ/Ⓡ 标在几何公差值之后（如 φ0.1Ⓜ A）。
04 表面结构（表面粗糙度） GB/T 1031-2009 · GB/T 131-2006

4.1 基本概念

表面结构描述零件表面的微观几何形状特征。几何误差按尺度分三层：宏观几何误差（形状公差）、表面波纹度、表面粗糙度（微观）——三者按波距区分，粗糙度是波距最小的微观不平度。

参数名称定义要点
Ra轮廓算术平均偏差取样长度 lr 内轮廓偏距绝对值的算术平均值（最常用）
Rz轮廓最大高度取样长度内最大轮廓峰高与最大轮廓谷深之和（旧标准曾指十点高度）
Rq轮廓均方根偏差轮廓偏距平方的平均值开方，对异常点更敏感
RSm轮廓单元的平均宽度间距参数，反映表面纹理疏密
lr / ln取样长度 / 评定长度评定长度 ln 通常含 5 个取样长度（ln ≈ 5×lr），数值越大取 lr、ln 越大

Ra 标准数值采用优先数系，第一系列（μm）：0.012、0.025、0.05、0.1、0.2、0.4、0.8、1.6、3.2、6.3、12.5、25、50、100。数值越大表面越粗糙。

工程常识：Ra 0.8~1.6 一般加工面；Ra 0.4~0.8 精加工；Ra 0.1~0.4 高精度面；Ra 3.2~12.5 粗加工面。

要点补充：标注方法与取样长度选择

  • 表面结构符号：基本符号（√，仅表示表面，无加工要求）→ 去除材料（符号上加横线）→ 不去除材料（符号上加圆圈）。标注如 Ra 3.2（上限值）、Ra 3.2 max。
  • 取样长度 lr 与 Ra 对应（GB/T 1031-2009）：Ra ≤0.02 取 0.08 mm；0.02~0.2 取 0.25；0.2~10 取 0.8；10~80 取 8.0；评定长度 ln 一般为 5 个取样长度。
  • 经验关系：Rz ≈ 4×Ra（常规加工面）；标注时优先采用 Ra，第一系列数值优先。
  • 与尺寸/几何公差的关系：表面粗糙度影响耐磨性、疲劳强度、配合稳定性与密封，与形状公差（宏观）按波距区分、各自独立控制。
05 未注公差（一般公差） GB/T 1804-2000 · GB/T 1184-1996

5.1 线性尺寸一般公差（GB/T 1804-2000）

图样上不单独标注公差的尺寸，由一般公差约束。线性尺寸分为四级：f（精密）、m（中等）、c（粗糙）、v（最粗），一般图纸默认按 m 级。

角度尺寸的一般公差同样按 f/m/c/v 四级查表（如短边 ≤10mm 时 m 级为 ±1°）。一般公差在标题栏或技术要求中标注，如「未注公差按 GB/T 1804-m」。

未注公差 ≠ 无公差：未注尺寸仍受一般公差约束，检验与加工必须遵守；对配合性能有要求的尺寸必须单独标注公差。

  • 角度尺寸按短边长度分段查表；f 与 m 级数值相同（角度公差中二者取同值）。
  • 一般公差应在图样标题栏或技术要求中说明，如「未注尺寸公差按 GB/T 1804-m」。
  • 未注公差不适用对象：配合尺寸、精密运动尺寸、与功能相关的尺寸——这些必须单独标注。

5.2 形位公差未注公差（GB/T 1184-1996）

未单独标注的几何公差按 H、K、L 三级控制（H 最严、K 中等、L 宽松），标注方式如「未注形位公差按 GB/T 1184-K」。需要注意：未注形位公差适用于直线度、平面度、垂直度、对称度、圆跳动等项目，但位置度必须单独标注。

要点补充：适用范围与工程习惯

  • 未注公差值按基本尺寸分段查表（GB/T 1184-1996 附表），如直线度、平面度取主参数 L；垂直度、对称度取短边；圆跳动取直径。
  • K 级为常用默认级；对运动精度、密封、装配有要求的几何公差必须单独标注，不得依赖未注值。
  • 图样技术要求的规范写法：「未注形位公差按 GB/T 1184-K」与「未注尺寸公差按 GB/T 1804-m」可同时声明，二者互相独立。
