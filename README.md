# 公差知识库与答题库

机械精度设计与互换性课程学习工具：基于现行国家标准的系统知识库 + 89 道分类练习题。每道题无论答对答错，都能一键跳转到对应知识点位置，边刷题边补课。

## 功能特性

- **知识库**：6 大章节系统梳理 —— 尺寸公差与配合、几何公差（GD&T）、公差原则、表面粗糙度、未注公差、标准速查，均依据现行有效国标整理
- **答题库**：89 道题（单选 / 判断 / 计算）按 7 个分类练习，支持抽题数量选择
- **即时解析**：作答后立即显示答案与解析，答对答错都给出「关联知识点 → 去学习」入口
- **智能跳转**：一键滚动定位到对应知识点卡片并高亮，错题可随时回顾
- **单文件 HTML**：纯前端、零依赖、无网络请求，下载后双击即可使用，手机电脑通用

## 依据标准（均现行有效，来源：全国标准信息公共服务平台）

| 标准号 | 内容 |
| --- | --- |
| GB/T 1800.1-2020 / GB/T 1800.2-2020 | 尺寸公差 ISO 代号体系 |
| GB/T 1182-2018 | 几何公差 形状、方向、位置和跳动公差标注 |
| GB/T 4249-2018 | 公差原则 |
| GB/T 16671-2018 | 最大实体要求、最小实体要求和可逆要求 |
| GB/T 17851-2022 | 几何公差 基准和基准体系 |
| GB/T 18780.1-2002 | GPS 几何要素 |
| GB/T 1804-2000 / GB/T 1184-1996 | 未注公差 |
| GB/T 1031-2009 / GB/T 3505-2009 / GB/T 131-2006 | 表面粗糙度与表面结构 |
